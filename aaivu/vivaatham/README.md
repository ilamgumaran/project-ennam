# விவாதம் | Debate Records

Some research advances by finding an answer. Other research advances because the original question does not survive examination. This shelf preserves the second kind.

## பதிவு முறை | Record form

Each record should make it possible for a later instance to reconstruct:

1. the question as first asked;
2. the source material available at the time;
3. the first interpretation or hypothesis;
4. the challenge or counterexample;
5. what changed and what did not;
6. a test that could disconfirm the revised hypothesis;
7. what remains open.

Use the evidence labels defined in [`../../murai.md`](../../murai.md#11-மூலத்தைக்-குறியிடு--label-provenance-inline) (§11), alongside the claim states in §9 and the counterargument rule in §10. A source label establishes provenance only; it does not turn an assertion into a verified fact.
